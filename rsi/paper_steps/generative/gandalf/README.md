# GANDALF-derived component

The files `gandalf/train/models.py`, `gandalf/train/data_preparation.py`,
`gandalf/train/utils.py` and `gandalf/train/train_cli.py` derive from
[GANDALF](https://github.com/raul-santovena/gandalf) by Raúl Santoveña Gómez
and use the upstream GPL version 3 license supplied in `LICENSE.txt`.
RSI adapts the training command examples and provides the surrounding
preparation and sampling utilities.
